# Fitness Log

Personal web app for logging meals and weight-training workouts.

pnpm monorepo:

| Package | What |
|---|---|
| `apps/web` | React + Vite, TanStack Router / Query / Form, Tailwind v4, shadcn/ui |
| `apps/api` | Express 5 + Drizzle ORM + Better Auth, run with `tsx` |
| `packages/shared` | Zod schemas, inferred types and pure logic shared by web and api |

## Prerequisites

- Node 24+
- pnpm 10+ (`corepack enable` works)
- Docker (for Postgres 16)

## Setup

```bash
pnpm install
cp .env.example .env
# put a real secret in .env:
#   BETTER_AUTH_SECRET=$(openssl rand -base64 32)

docker compose up -d     # Postgres on :5432, creates `fitness` and `fitness_test`
pnpm db:migrate          # apply migrations in apps/api/drizzle
pnpm db:seed             # global foods + exercises (safe to re-run)
pnpm dev                 # api on :4000, web on http://localhost:5180
```

Open http://localhost:5180. The web dev server proxies `/api/*` to the API, so
the browser only ever sees one origin (no CORS, first-party cookies).

## Environment variables

All in the root `.env` (loaded with Node's built-in `--env-file`).

| Var | Used by | Notes |
|---|---|---|
| `DATABASE_URL` | api, drizzle-kit | dev database |
| `TEST_DATABASE_URL` | api tests | separate DB, truncated by tests |
| `PORT` | api, vite proxy | default 4000 |
| `WEB_PORT` | vite | default 5180; keep `BETTER_AUTH_URL` in sync |
| `BETTER_AUTH_SECRET` | api | ≥ 32 chars, signs session cookies |
| `BETTER_AUTH_URL` | api | public origin the browser uses — the Vite URL in dev |

## Conventions

- **Dates**: `log_date` columns are Postgres `DATE` holding the user's local
  calendar day (Asia/Bangkok), passed around as `"YYYY-MM-DD"` strings — never
  as JS `Date`. See `packages/shared/src/logic/date.ts`.
- **Units**: weight is always stored in kg.
- **Errors**: every API error is `{ "error": { "code": "...", "message": "..." } }`.
- **Auth tables** (`apps/api/src/db/schema/auth.ts`) are generated by
  `pnpm dlx @better-auth/cli generate` — regenerate rather than hand-edit.
